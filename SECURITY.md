# Security policy

## Supported versions

This project is a Public Preview. Only the latest GitHub release is supported;
preview interfaces and output schemas may change before 1.0.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability or disclosure of
customer data. Email **support@motherduck.com** with the subject
`Security: md-migration-assessment` and include:

- the affected version;
- reproduction steps and impact;
- whether credentials or customer data may have been exposed; and
- a safe way to contact you for follow-up.

Do not attach assessment or handoff databases unless MotherDuck Support provides
an approved transfer method. MotherDuck will coordinate triage and remediation
privately with the reporter.
