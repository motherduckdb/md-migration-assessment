# Support

`md-migration-assessment` is maintained by MotherDuck and is available as a
Public Preview for qualified prospects and customers.

For setup help, collection failures, questions about assessment output, or bug
reports, email **support@motherduck.com** and mention
`md-migration-assessment` in the subject. Include the tool version, command used,
and redacted error output. Do not send credentials, raw assessment databases, or
handoff databases through ordinary email.

Preview releases do not carry a public compatibility or response-time SLA.
MotherDuck will communicate breaking schema changes in release notes.

Security issues must follow [SECURITY.md](SECURITY.md).
